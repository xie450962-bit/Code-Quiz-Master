このアプリには以下の3つのゲームがあります。

* Typing Game
* SQL Quiz
* Linux Quiz

認証機能はまだ実装しません。
ユーザー選択画面で仮のユーザーを選択できる形にしてください。

現時点では、SSO、管理者機能、ランキング、課題管理などは実装しないでください。

## HOMEの仕様

HOMEはゲームを選択するためだけのシンプルな画面にしてください。

表示するもの：

* アプリ名
* 現在選択されている仮ユーザー
* Typing
* SQL
* Linux

HOMEには以下を表示しないでください。

* スコア
* 過去の結果
* 自己ベスト
* プレイ履歴
* ランキング
* 学習状況
* 課題
* その他の学習情報

## 各ゲーム画面について

Phase 1ではゲームそのもののロジックは実装しません。

Typing Game：

* ゲーム画面のレイアウトだけ作る
* 仮のお題文章を表示してよい
* タイマーはまだ実装しない
* タイピング判定はまだ実装しない

SQL Quiz：

* 問題表示エリア
* 選択肢エリア
* 回答ボタンなどのレイアウトを作る
* 正誤判定はまだ実装しない

Linux Quiz：

* SQL Quizと同様に画面の骨格を作る
* 正誤判定はまだ実装しない

## Result画面

Result画面には、後から実装する以下の表示領域を用意してください。

* 今回

ただしPhase 1では実際の結果計算や保存は行いません。
仮の値を表示しても構いません。

## UIについて

新人エンジニアが使う社内学習アプリとして、シンプルで見やすいUIにしてください。

過度な装飾やゲームセンター風の派手なUIにはしないでください。

PCブラウザでの利用を主な対象としてください。
